# Association Rule Learning — Market Basket Analysis of the Groceries Dataset

Unsupervised learning assignment applying the **Apriori algorithm** to the
classic `Groceries` transaction dataset (9,835 transactions, 169 items) to
discover frequent itemsets and association rules, and to interpret
**support**, **confidence**, and **lift**.

## Contents

- `association_rule_learning_groceries.ipynb` — analysis notebook, answers Q1–Q8
- `groceries.csv` — transaction data (basket format: one shopping trip per line)
- `figures/` — chart images generated by the notebook

## Highlights

- 9,835 transactions, 169 distinct items, average basket size 4.41 items
- 245 frequent itemsets (size ≥ 2) at 1% minimum support
- 170 association rules at 25% minimum confidence
- Strongest patterns concentrated in fresh produce (root vegetables, other
  vegetables, tropical fruit, citrus fruit)

## Setup

```bash
pip install -r requirements.txt
```

Then open and run `association_rule_learning_groceries.ipynb` top to bottom.
The notebook looks for `groceries.csv` next to itself or in a `data/`
subfolder.

## Method

- **Encoding:** `mlxtend.preprocessing.TransactionEncoder` converts the
  basket-format transactions into a one-hot boolean matrix.
- **Frequent itemsets:** `mlxtend.frequent_patterns.apriori`, minimum support
  = 0.01.
- **Rules:** `mlxtend.frequent_patterns.association_rules`, minimum
  confidence = 0.25, ranked primarily by lift.
